## Study summary

The study matches AI Incident Database (AIID) failures involving U.S.-listed companies
to those companies’ investor disclosures and codes whether each incident appears in
disclosure text.

**Main findings regenerated by this artifact** (N = 307 matchable incidents · 21 issuers):

- Incident-specific disclosure **1.3%** [0.4, 3.3]
- Substantive disclosure (T1+T2) **2.3%** [1.1, 4.6]
- Disclosure shadow (T3+T4) **97.7%** [95.4, 99.1]  
  (issuer-clustered bootstrap 97.5% [93.9, 99.6])
- Tier counts T1/T2/T3/T4 = 4/3/278/22

## How to reproduce

### Code Ocean

Capsule: https://doi.org/10.24433/CO.2340354.v1

1. Open the compute capsule.
2. Click **Reproducible Run** (`/code/run`).
3. Inspect `/results` (`results.md`, extended/reliability reports, `figures/`).

### Local

```bash
git clone https://github.com/samirrc2/ai-incident-disclosure-shadow.git
cd ai-incident-disclosure-shadow
python3.12 -m venv .venv && source .venv/bin/activate   # Python ≥3.12 recommended
pip install -r code/requirements.txt
bash reproduce.sh
```

Expect claim-check **PASS**, determinism **PASS**, and pytest green (~1 minute).

### What the run does

| Step | Script | Produces / checks |
|------|--------|-------------------|
| 0 | `verify_inputs.py` | SHA-256 of frozen assets vs `data/MANIFEST.sha256` |
| 1 | `resolve.py` | entity resolution; **N_matchable = 307** |
| 2 | `rebuild_coded_table.py` | rebuild codes from logs + corrections |
| 3–5 | analysis / extended / reliability | results JSON/MD |
| 6 | `make_figures.py` | Figures 1–5 |
| 7–8 | `check_claims*.py` | assert every headline/extended number |
| — | determinism + `pytest` | byte-identical re-run + unit tests |
