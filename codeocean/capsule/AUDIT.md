## 1. Reproducibility model (read first)
The paper's disclosure labels were produced by point-in-time SEC EDGAR full-text search (network,
time-sensitive) and two-pass human-validated coding. As with a frozen LLM-API dataset, that retrieval
is **not re-executed**; the **coded table and per-incident search logs are frozen and SHA-256-pinned**,
and the capsule regenerates every published number and figure from them **offline**. The (network)
retrieval protocol that produced the logs is documented, non-executed, in `code/provenance/`.
`code/src/rebuild_coded_table.py` proves the codes are a deterministic function of the shipped logs +
documented corrections. This is the same model Code Ocean accepts for API/instrument-derived datasets.

## 5. How to publish on Code Ocean
1. Create a new capsule → upload this folder's contents into the matching mounts (`code/`, `data/`,
   `environment/`, `metadata/`, `results/`).
2. Confirm the environment builds from `environment/Dockerfile` (Code Ocean rewrites the `# hash:` line
   on first build — expected).
3. Press **Reproducible Run**; it executes `code/run`. Expect the console to end with
   "REPRODUCTION COMPLETE" and all verifiers PASS.
4. (Optional) attach the full 105 MB AIID snapshot as an external data asset if you want the raw
   snapshot→`incidents.csv` extraction inside the capsule; not required — the extracted, hashed
   `incidents.csv` is already shipped and its provenance SHA is in `archive_manifest.md`.
